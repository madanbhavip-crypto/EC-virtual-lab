# EC Virtual Lab

A software-based Electronics and Communication Engineering Virtual Laboratory.

## Features

- Logic Gate Simulator
- Virtual Oscilloscope
- 555 Timer Simulator (Coming Soon)
- RC Circuit Analyzer (Coming Soon)
- AM/FM Communication Simulator (Coming Soon)

## Technologies Used

- Python
- CustomTkinter
- NumPy
- Matplotlib

## Run

```bash
pip install -r requirements.txt
python main.py
